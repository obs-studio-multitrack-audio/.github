## Troubleshooting Common Issues

Install issues? Set the sample rate to match all sources, since a mismatch causes pitch or timing drift.  
Performance problems? Check the output track count before a long recording.  
License/activation? Disable monitoring on sources that cause echo.  
Compatibility? Remux a recording rather than re-encoding when the container is the only problem.  
Update failures? Verify each source appears in the mixer before starting.
